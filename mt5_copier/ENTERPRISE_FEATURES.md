# MT5 Trade Copier - 企业级功能指南

## 概述

MT5 Trade Copier 现已升级为企业级跟单系统，提供了全面的风险管理、实时监控、交易历史分析等专业功能。

## 高级符号映射系统

### 概述

企业版的 MT5 Trade Copier 提供了强大的符号映射系统，允许在不同经纪商和不同账户类型之间准确复制交易，即使交易品种名称不同。

### 功能亮点

- **灵活的符号映射**：为每个跟单账户单独配置符号映射规则
- **自动符号检测**：系统会自动检测可用符号并提供匹配建议
- **点值比率调整**：自动计算不同经纪商之间的点值比率，确保止损/止盈水平一致
- **手数自动调整**：根据不同品种的合约大小自动调整跟单手数

### 配置示例

```json
"symbol_mapping": {
    "EURUSD": "EURUSD.e",
    "GBPUSD": "GBPUSD-sb",
    "USDJPY": "USD/JPY",
    "XAUUSD": "GOLD"
}
```

## 核心企业级功能

### 1. 实时监控仪表板

全新的仪表板提供一目了然的系统状态：

- **关键指标卡片**
  - 总交易数（含变化趋势）
  - 成功率
  - 总盈亏（含实时变化）
  - 活跃持仓数

- **账户状态监控**
  - 所有账户的实时连接状态
  - 余额、净值、保证金信息
  - 风险级别可视化
  - 自动刷新（可配置间隔）

- **系统健康状态**
  - EA连接状态
  - 工作进程监控
  - 最后交易时间
  - 系统健康度评分

### 2. 高级品种映射

手动配置品种映射，确保跟单准确性：

- **智能品种匹配**
  - 自动检测可用品种
  - 手动输入映射关系
  - 实时验证品种有效性
  - 支持批量配置

- **使用方法**
  1. 在账户管理页面选择账户
  2. 点击"品种映射"按钮
  3. 添加主账户品种和对应的跟单账户品种
  4. 点击"验证"确认品种有效
  5. 保存配置

### 3. 交易历史管理

完整的交易历史记录和分析：

- **数据存储**
  - SQLite数据库存储所有交易记录
  - 自动记录执行时间、滑点、盈亏等
  - 支持长期数据保存

- **查询功能**
  - 按日期范围查询
  - 按账户筛选
  - 状态筛选（成功/失败）
  - 导出CSV报表

- **统计分析**
  - 总交易量统计
  - 成功率分析
  - 盈亏汇总
  - 平均执行时间
  - 滑点分析

### 4. 企业级风险管理

全面的风险控制功能：

#### 资金风险控制
- **每日亏损限制**
  - 金额限制（如：最大亏损$1000）
  - 百分比限制（如：最大亏损5%）

- **回撤控制**
  - 最大回撤百分比设置
  - 自动监控和警告

- **保证金管理**
  - 最小可用保证金百分比
  - 保证金水平监控

#### 交易风险控制
- **持仓限制**
  - 最大持仓数量
  - 单笔最大手数
  - 总持仓最大手数
  - 相关品种持仓限制

- **交易时间控制**
  - 允许交易时间段设置
  - 排除特定日期
  - 排除特定星期几

- **品种限制**
  - 允许/禁止特定品种
  - 每个品种的最大手数

#### 策略风险控制
- **强制止损止盈**
  - 必须设置SL/TP
  - 最大止损点数限制
  - 最小风险回报比

### 5. 高级手数计算

三种手数计算模式：

1. **固定手数**
   ```json
   "lot_mode": "fixed",
   "lot_value": 0.1
   ```

2. **倍数模式**
   ```json
   "lot_mode": "multiplier",
   "lot_value": 2.0
   ```

3. **风险百分比** (NEW!)
   ```json
   "lot_mode": "risk_percentage",
   "lot_value": 2.0  // 风险2%
   ```

### 6. 紧急控制功能

- **暂停所有交易**
  - 一键暂停新的跟单操作
  - 不影响现有持仓

- **紧急平仓**
  - 平仓所有跟单账户的所有持仓
  - 双重确认保护

### 7. 性能优化

- **并行处理**
  - 多账户并行执行
  - 异步品种信息获取
  - 工作进程池管理

- **智能重试**
  - 失败交易自动重试
  - 可配置重试次数和延迟

- **连接池管理**
  - MT5连接复用
  - 减少连接开销

## 故障处理

### 品种映射失败
1. 检查品种名称拼写
2. 确认品种在MT5中可用
3. 使用"自动检测"功能
4. 手动输入正确的品种名

### 风险限制触发
1. 检查风险设置是否合理
2. 查看交易历史找出问题
3. 调整风险参数
4. 考虑暂停交易进行调整

### 性能问题
1. 减少同时跟单的账户数
2. 增加重试延迟时间
3. 优化品种映射减少查询
4. 考虑使用更快的服务器
